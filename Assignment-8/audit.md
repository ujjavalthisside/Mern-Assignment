# RESPONSIVE WEBSITE AUDIT

## Project Name
Midnight Coffee

## Objective
To make the Midnight Coffee website
responsive for desktop, tablet and mobile screens.

## Technologies Used
- HTML
- CSS
- Flexbox
- Media Queries

## Breakpoints Used
- Desktop: Above 768px
- Tablet: 768px
- Mobile: 480px

## Problems Found and Fixed

### 1. Navbar Overflow
Problem: Navigation menu was not properly adjusted.

Solution: Used flex-direction column
for smaller screens.

### 2. Menu Cards
Problem: Menu cards were not fitting on mobile screens.

Solution: Used flex-wrap and flex-direction.

### 3. Text Size
Problem: Heading text was too large on mobile.

Solution: Reduced font size using media queries.

### 4. Spacing Problem
Problem: Sections and cards had improper spacing.

Solution: Added proper padding and gap.

### 5. Horizontal Scrolling
Problem: Content could overflow on smaller screens.

Solution: Used box-sizing: border-box
and responsive widths.

## Testing Screen Sizes

- Desktop: 1200px
- Tablet: 768px
- Mobile: 375px

## Final Result

The Midnight Coffee website is designed
to work on desktop, tablet and mobile screens.

The layout adjusts according to screen size.

Horizontal scrolling should not appear
after successful testing.

## Conclusion

Successfully completed the Responsive
Website Audit using HTML and CSS.
